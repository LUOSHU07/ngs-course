# 干实验全流程：从 FASTQ 到结果

> 目标：在一台 Linux 机器（或 WSL / 服务器）上，把原始测序数据跑到可解释的结果。
> 原则：命令可复制、版本可追溯、每一步留下日志。
> 云端执行：没有本地 Linux 时，按 [玻尔云容器使用](01-玻尔云容器使用.md) 在 Bohrium 容器节点运行。

## 0. 环境与目录

```bash
# 建议用 conda 管理环境
conda create -n ngs -c conda-forge -c bioconda fastqc fastp bwa-mem2 samtools subread salmon multiqc
conda activate ngs
```

项目目录：

```text
project/
├── raw/          # 原始 FASTQ（只读）
├── qc/           # FastQC / fastp 报告
├── trimmed/      # 清洗后 FASTQ
├── ref/          # 参考基因组与注释
├── bam/          # 比对结果
├── counts/       # 定量结果
├── results/      # 图表与报告
└── scripts/      # 所有命令与脚本
```

## 1. Linux 最小命令集

```bash
pwd; ls -lh; cd project
cp -r raw raw_backup        # 备份，不改原始数据
grep -c '^@' raw/sample_R1.fastq.gz   # 粗略计数
zcat raw/sample_R1.fastq.gz | head -8 # 看前两条 read
tar -czf results.tar.gz results
```

远程会话用 `tmux` 或 `screen`，避免断线中断任务。

## 2. FASTQ 格式

- 每条 read 4 行：`@标题`、序列、`+`、质量值。
- Phred33：Q = ASCII − 33；Q30 表示错误率 0.1%。
- 双端测序：`R1` 与 `R2` 文件一一对应，顺序必须一致。

## 3. 质控与清洗

> 每一步的"为什么"与避坑见 [实操 07](07-定量与差异分析实操.md) 的「每步原理与技巧」节（FastQC/Trim/HISAT2/featureCounts/DESeq2 五命令逐条剖析）。注意：本页清洗用 **fastp**，07 剖析的是 **Trim Galore**，两者修剪算法不同（fastp 滑动窗口、Trim Galore 逐碱基累计分），别把参数与机理串用。

```bash
fastqc -t 8 -o qc raw/*.fastq.gz
multiqc qc -o qc/multiqc

fastp -i raw/sample_R1.fastq.gz -I raw/sample_R2.fastq.gz \
      -o trimmed/sample_R1.fq.gz -O trimmed/sample_R2.fq.gz \
      -q 20 -l 50 -j qc/sample.fastp.json -h qc/sample.fastp.html
```

看什么：Q30、接头含量、重复率、GC 分布、过表达序列。

## 4. 比对

### DNA

```bash
bwa-mem2 index ref/genome.fa
bwa-mem2 mem -t 8 ref/genome.fa trimmed/sample_R1.fq.gz trimmed/sample_R2.fq.gz \
  | samtools sort -@ 4 -o bam/sample.bam -
samtools index bam/sample.bam
samtools flagstat bam/sample.bam
```

### RNA

```bash
hisat2-build ref/genome.fa ref/genome_index
hisat2 -p 8 -x ref/genome_index -1 trimmed/sample_R1.fq.gz -2 trimmed/sample_R2.fq.gz \
  | samtools sort -@ 4 -o bam/sample.bam -
samtools index bam/sample.bam
```

看什么：比对率、唯一比对率、插入片段、rRNA 比例、覆盖均匀性。

## 5. 定量

### 基因水平（featureCounts）

```bash
featureCounts -T 8 -p -a ref/annotation.gtf -o counts/all_counts.txt bam/*.bam
```

### 转录本水平（Salmon）

```bash
salmon index -t ref/transcriptome.fa -i ref/salmon_idx
salmon quant -i ref/salmon_idx -l A \
  -1 trimmed/sample_R1.fq.gz -2 trimmed/sample_R2.fq.gz -o counts/sample_quant
```

## 6. 差异分析（R / DESeq2）

```r
library(DESeq2)
counts <- read.delim("counts/all_counts.txt", row.names = 1, check.names = FALSE)
coldata <- data.frame(
  row.names = colnames(counts),
  condition = factor(c("control", "control", "treat", "treat"))
)
dds <- DESeqDataSetFromMatrix(counts, coldata, ~ condition)
dds <- DESeq(dds)
res <- results(dds)
write.csv(as.data.frame(res), "results/deseq2_results.csv")
```

看什么：标准化是否合理、PCA 是否分组、差异基因数量与方向、是否受批次影响。

## 7. 变异检测（可选，DNA）

```bash
bwa-mem2 mem -t 8 ref/genome.fa trimmed/sample_R1.fq.gz trimmed/sample_R2.fq.gz \
  | samtools sort -o bam/sample.bam -
samtools index bam/sample.bam
```

## 8. 组装与注释（可选）

- 宏基因组：`megahit` / `spades` 组装，`prokka` / `bakta` 注释。
- 质量评估：`QUAST`、`BUSCO`。

## 9. 可重复性与资源

- 固定版本：`conda env export > environment.yml`。
- 每个命令写入 `scripts/`，日志重定向到 `logs/`。
- 流程管理：样本多时用 Nextflow 或 Snakemake。
- 资源估算（经验值，需实测）：人类 WGS 30× 的 FASTQ 约数十 GB；BWA-MEM2 比对建议 32 GB 以上内存；RNA-seq 小数据可在 16 GB 机器完成。

## 10. 常见问题

| 现象 | 可能原因 | 处理 |
|------|----------|------|
| 比对率低 | 接头残留、污染、参考不匹配 | 重新 trim、查阴性对照、核对物种 |
| rRNA 比例高 | rRNA 去除不完全 | 换去除试剂盒或增加去除步骤 |
| 差异基因过少 | 测序深度不足、批次混杂 | 增加深度、加协变量 |
| 结果不可重复 | 版本/参数不一致 | 固定环境、记录命令 |

## 分步细节与技巧

### 质控（FastQC）

- 重点看 Per base sequence quality、Adapter content、Sequence duplication、GC distribution。
- 过表达序列提示污染或低多样性；rRNA 残留会在 RNA-seq 中明显。
- 技巧：RNA-seq 的高重复率可能来自高表达基因，不要一律判失败。

### 清洗（fastp）

- 常用参数：`-q 20 -l 50`；双端加 `--detect_adapter_for_pe`；polyG 用 `--trim_poly_g`。
- 保留 `fastp.json` 与 `fastp.html` 作为批次记录。
- 技巧：先不 trim 跑 FastQC 确认接头类型；过度 trim 会降低比对率。

### 比对

- DNA：`bwa-mem2 index` → `mem` → `samtools sort` → `markdup` 去重。
- RNA：HISAT2 或 STAR；注意链特异性，后续 featureCounts 的 `-s` 要一致。
- 技巧：人/鼠加 decoy 序列；MAPQ <20 的 reads 在变异检测中慎用。

### 定量

- featureCounts：`-p --countReadPairs`；`-s` 与建库链特异性一致。
- Salmon：`-l A` 自动判断，或明确 `-l ISF/ISR`。
- 技巧：rRNA 比例高先查去除效率，不要直接进 DESeq2。

### 差异分析

- 预过滤低表达基因；DESeq2 估计 size factor 与离散度；LFC shrink；独立过滤。
- 技巧：批次与协变量写进 design；先看 PCA 排除离群样本。

### 变异检测

- GATK：MarkDuplicates → BQSR → HaplotypeCaller → VQSR/硬过滤。
- 技巧：肿瘤样本需配对正常；panel 用 UMI 去重；不要用低 MAPQ reads 强行 call。

### 组装与注释

- 宏基因组：MEGAHIT/metaSPAdes；QUAST 评估；BUSCO 看完整性。
- 技巧：多 k-mer 组装后择优，不要只跑一个 k。

### 可重复性

- `conda env export > environment.yml`；脚本与日志入 git；记录 `sessionInfo()`。
- 技巧：参考基因组版本与注释版本必须成对记录，否则差异结果无法复现。
