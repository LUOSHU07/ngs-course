# SPRI 磁珠纯化与片段选择（原理 + 已核对比例汇总）

> "提取纯化"的纯化一半：建库每一步之间的纯化与片段选择都靠 SPRI 磁珠（AMPure XP / SPRIselect / 各厂等效磁珠）。本页把已核对协议中的比例与条件汇总成一张表，并讲清原理与常见错误。

## 1. 原理（30 秒版）

- 磁珠悬浮液含 **PEG + NaCl**：PEG 浓度越高，能结合的 DNA 越短。
- **磁珠比例（X×）= 磁珠体积 ÷ 样本体积**：比例越高 → 回收越短的片段。
- 常规纯化用高比例（0.8×–3.1×）全回收；**片段选择**用两次加珠：
  - 第一次低比例（如 0.4×）：大片段先结合 → **弃珠留上清**；
  - 第二次补加（如再 0.2×，累计 0.6×）：目标片段结合 → **弃上清留珠**。
- 80% 乙醇洗去 PEG/盐；晾干到哑光（开裂 = 过干，得率降）；低盐（TE/EB/水）洗脱。

## 3. 比例直觉表（片段选择）

| 目的 | 典型比例 | 效果 |
|------|----------|------|
| 全回收纯化 | 0.8×–1.8× | 去盐/酶/接头，不选片段 |
| 去接头 dimer | 0.8×–0.9× 重复一次 | dimer（128 bp 附近）不进珠 |
| 长读长全回收 | 3.1×（PacBio） | 超高 PEG 确保大片段全收 |
| 左选择（去长） | 0.4× 弃珠 | 去掉 >700 bp 左右 |
| 右选择（去短） | 累计 0.6× 留珠 | 去掉 <300 bp 左右 |

> 具体 cutoff 随 PEG 浓度、盐、温度、片段分布漂移，以上为已核对协议中的典型值；换磁珠品牌必须重新优化。

## 4. 操作红线（多手册共同强调）

1. **磁珠室温平衡 ≥30 min**（冷珠结合效率低且不可重复），用前充分涡旋。
2. **80% 乙醇现配**（乙醇挥发浓度漂移）；洗时沿壁加，勿冲散珠团。
3. **晾干到哑光不开裂**：过干（开裂）→ 洗脱不下来；未干 → 乙醇带入下游。
4. 洗脱液点珠团上，吹打 ≥10 次或涡旋重悬，室温静置 ≥2–10 min 再上磁力架。
5. 片段选择的**两次加珠顺序不能反**：先低比例去长，后补加选目标。
6. 长片段（>3 kb）避免剧烈吹打与乙醇（ONT 用 LFB/SFB 洗液代替）。

## 5. 常见错误速查

| 现象 | 最可能原因 |
|------|------------|
| 得率整体偏低 | 磁珠未回温 / 晾干过度 / 洗脱时间不足 |
| 小片段拖尾残留 | 比例偏高或只做了一次选择；补做 0.9× |
| dimer 峰仍在 | 第二次 PEG/NaCl 纯化被省略（KAPA RNA 明确不可省） |
| 下游酶反应被抑制 | 乙醇带入（未干透）或 PEG 带入（洗不够） |
| 大片段丢失 | 比例过高后弃珠时把目标带走了 / 吹打过猛剪切 |

## 6. 计算

磁珠体积 = 样本体积 × 比例。工作台「计算与成本」的磁珠纯化计算器直接算；多次加珠用累计体积判断。
