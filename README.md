# NGS 从零到一：湿实验 + 干实验全流程

本课程面向**没有测序经验**的本科生、研究生和实验员，目标是在 4 周内建立一条可独立跑通的 NGS 链路：样本进、数据出、成本算得清。内容覆盖湿实验、干实验、设备使用与维护、浓度换算与成本核算。

> **定位**：课程文档（本目录各章）是主体，[interactive 工作台](interactive/) 是辅助工具——它把课程里的清单、计算器和厂家协议做成可交互的学习支架，但不替代阅读与动手。开发原则：**每一分工作台投入都要回答"这对学习有什么帮助"**；内容优先级永远高于工具功能。

## 快速开始

- **先看大纲**：从 [00-课程大纲](00-课程大纲.md) 开始，按「4 周学习计划」推进。
- **边看边练**：双击 [interactive/index.html](interactive/index.html) 打开离线练习台——无需服务器、无需安装，内置学习路径、清单、计算器、厂家协议与自测，数据只存本机浏览器。
- **干实验**：按 [02-干实验全流程](02-干实验/00-干实验全流程.md) 的命令在 Linux（或 WSL / 玻尔云容器）逐条执行。

## 结课后你能独立完成

1. 接收并登记样本，完成 gDNA / 总 RNA 提取与初检。
2. 按试剂盒说明完成 DNA-seq 或 RNA-seq 文库构建。
3. 用 Qubit、Bioanalyzer / TapeStation、qPCR 对文库做质量与定量判断。
4. 按摩尔浓度等摩尔 pooling，计算 PhiX 比例与上机稀释。
5. 在 Linux 上完成 FASTQ 质控、比对、定量与差异分析。
6. 为一次测序项目做单样本成本核算，并解释成本结构。

## 4 周学习计划

| 周 | 湿实验 | 干实验 | 产出 |
|----|--------|--------|------|
| 第 1 周 | 安全分区、移液、样本登记、核酸提取 | Linux 基础、FASTQ 格式 | 提取记录 + 第一条 Linux 流程 |
| 第 2 周 | 文库构建、纯化、QC | FastQC / fastp、比对 | 文库 QC 报告 |
| 第 3 周 | 定量、pooling、上机 | featureCounts / Salmon、DESeq2 | 表达矩阵 + 差异结果 |
| 第 4 周 | 运行监控、故障复盘 | 可视化、报告 | 一份完整项目报告 + 成本表 |

时间紧时可只做 DNA-seq 主线；RNA-seq 作为扩展。

## 先修、设备与耗材

- 先修：高中生物 + 基础化学；会装软件即可，不要求编程。
- 最低设备：移液器、涡旋仪、小型离心机、PCR 仪、Qubit、磁力架、冰箱（-20 ℃）、超低温冰箱（-80 ℃）。
- 建库与测序设备：Bioanalyzer / TapeStation、qPCR 仪、测序仪（Illumina 或 MGI）；没有测序仪时可用核心设施或外包。
- 干实验：一台 16 GB 内存以上的电脑；大基因组比对建议 32 GB 以上或使用服务器。

## 安全、伦理与合规

- 人类样本须有伦理批件与知情同意；临床样本按生物安全二级（BSL-2）操作。
- 实验分区单向流：试剂配制 → 样本处理 → 扩增 → 测序，避免气溶胶污染。
- 废弃物、尖锐物、核酸染料按实验室规定处理。
- 数据去标识化，原始数据与临床信息分开存放。

## 关于价格

课程中的价格均为 **2026 年公开资料的区间或示例**，用于建立成本意识；实际采购须以当地供应商报价为准。成本模型脚本允许你把单价替换成本地价格。
