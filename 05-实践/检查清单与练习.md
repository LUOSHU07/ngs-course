# 检查清单与练习

## 每周练习

### 第 1 周

- [ ] 画出实验室分区与单向流示意图。
- [ ] 用移液器做 1 µL、10 µL、100 µL 的称重校验，记录偏差。
- [ ] 提取一份 gDNA 或 RNA，记录 Qubit、A260/280、A260/230。
- [ ] 在 Linux 上创建项目目录，跑通 `fastqc --version`。

### 第 2 周

- [ ] 完成一次建库（或观看并记录演示），写清输入量、循环数、index。
- [ ] 用 TapeStation / Bioanalyzer 判断主峰与 adapter dimer。
- [ ] 用 qPCR 与 Qubit 各测一次，比较差异。
- [ ] 用 fastp 清洗一组公共 FASTQ，读 MultiQC 报告。

### 第 3 周

- [ ] 完成比对，记录比对率与覆盖度。
- [ ] 用 featureCounts 或 Salmon 得到表达矩阵。
- [ ] 用 DESeq2 做差异分析，画火山图与 PCA。
- [ ] 计算 4 个文库的等摩尔 pooling 体积。

### 第 4 周

- [ ] 做一次单样本成本核算，写出成本结构。
- [ ] 写一份可交接的 SOP。
- [ ] 复盘一次失败或异常，给出排查路径。

## 湿实验上机前检查清单

- [ ] 样本编号与登记表一致，无重复。
- [ ] 核酸浓度、纯度、完整性达标。
- [ ] 试剂在有效期内，批次已记录。
- [ ] 阴性对照已设置。
- [ ] 移液器、离心机、PCR 仪状态正常。
- [ ] 建库区与扩增区耗材未混用。

## 文库上机前检查清单

- [ ] Qubit 总量足够。
- [ ] TapeStation 主峰在预期范围，无 adapter dimer。
- [ ] qPCR 有效浓度已测。
- [ ] pooling 表按 nM 计算，体积核对。
- [ ] PhiX 比例已按文库多样性设定。
- [ ] 变性、稀释按当前平台说明书执行。

## 干实验检查清单

- [ ] 原始数据只读，已备份。
- [ ] 参考基因组版本与注释版本一致。
- [ ] 每条命令写入 `scripts/`，日志在 `logs/`。
- [ ] 环境已导出 `environment.yml`。
- [ ] 结果表与图能对应到具体样本与参数。

## 综合项目（Capstone）

选一个题目，完成从样本到报告：

1. **16S 微生物多样性**：提取 → 16S 建库 → 测序 → QIIME2 / DADA2 → 群落组成。
2. **RNA-seq 差异表达**：提取 → 建库 → 测序 → 比对 → 定量 → DESeq2 → 富集分析。
3. **WGS 变异检测**：提取 → 建库 → 测序 → 比对 → 变异检测 → 注释。

交付物：

- 项目报告（背景、方法、结果、讨论、局限）。
- SOP（可交接）。
- 成本表（分项 + 单样本）。
- 原始数据与脚本归档说明。
