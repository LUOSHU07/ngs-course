# 浓度与摩尔浓度计算

> 建库、pooling、上机的核心算术。所有公式都可手算，也可用 `tools/calc_molarity.py` 复核。

## 1. 两个浓度概念

- **质量浓度**：ng/µL，Qubit 测的是这个。
- **摩尔浓度**：nM，决定“有多少条文库分子”，pooling 与上机按这个算。

双链 DNA 的换算（1 bp ≈ 660 g/mol）：

```text
nM = (ng/µL × 10^6) / (片段长度 bp × 660)
```

反算：

```text
ng/µL = (nM × 片段长度 bp × 660) / 10^6
```

### 例 1

文库浓度 12 ng/µL，平均片段 450 bp：

```text
nM = 12 × 10^6 / (450 × 660) = 40.4 nM
```

### 例 2

目标 10 nM，片段 500 bp，需要多少 ng/µL？

```text
ng/µL = 10 × 500 × 660 / 10^6 = 3.3 ng/µL
```

## 2. 稀释：C1V1 = C2V2

把 100 nM 稀释到 2 nM，配 500 µL：

```text
V1 = C2 × V2 / C1 = 2 × 500 / 100 = 10 µL
加稀释液 490 µL
```

## 3. 等摩尔 pooling

n 个文库等摩尔混合，目标浓度 C_target、总体积 V_total：

```text
每个文库体积 V_i = (C_target × V_total / n) / C_i
```

其中 C_i 是该文库的摩尔浓度（nM）。

### 例 3

4 个文库，浓度分别为 40、25、30、20 nM；目标 10 nM、总 100 µL。

```text
每个文库贡献的摩尔量 = 10 nM × 100 µL / 4 = 250 nM·µL
V1 = 250 / 40 = 6.25 µL
V2 = 250 / 25 = 10.0 µL
V3 = 250 / 30 = 8.33 µL
V4 = 250 / 20 = 12.5 µL
补稀释液至 100 µL
```

### 不等摩尔混合

按目标比例 f_i（Σf_i = 1）：

```text
V_i = (C_target × V_total × f_i) / C_i
```

## 4. PhiX 比例

若 PhiX 与 pool 浓度一致，按体积比加入：

```text
V_phix = V_total × p
```

若浓度不同，先统一到同一浓度再加入，或用 C1V1 换算。

## 5. Qubit 与 qPCR 的区别

| 方法 | 测什么 | 用途 |
|------|--------|------|
| Qubit | 总 dsDNA 质量 | 判断总量、纯化后回收 |
| qPCR | 可扩增文库分子数 | **上机 loading 定量首选** |

两者差异过大（如 qPCR 远低于 Qubit）提示文库不可扩增或结构异常。

## 6. 上机 loading

- 不同平台、不同试剂盒的 loading 浓度不同，**以说明书为准**。
- 单位换算：1 nM = 1000 pM。
- 变性、稀释按平台流程；不要照搬旧参数。

## 7. 常用换算速查（dsDNA）

| 片段长度 | 1 ng/µL 对应 |
|----------|--------------|
| 200 bp | 7.58 nM |
| 300 bp | 5.05 nM |
| 400 bp | 3.79 nM |
| 500 bp | 3.03 nM |
| 600 bp | 2.53 nM |
