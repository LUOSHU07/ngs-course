# 成本核算模型

> 目的：让你在立项前算清“一个样本要花多少钱、钱花在哪、规模变化时怎么变”。
> 价格均为 2026 年公开资料的区间或示例，**实际以当地报价为准**；用 `tools/cost_model.py` 替换成本地单价。

## 1. 成本构成

| 类别 | 包含 | 计费方式 |
|------|------|----------|
| 试剂 | 提取、建库、QC、测序试剂 | 按样本或按 run |
| 耗材 | 吸头、管、磁珠、芯片、流动池 | 按样本/批次 |
| 设备折旧 | 测序仪、PCR 仪、Qubit、TapeStation | 按年折旧分摊 |
| 人工 | 提取、建库、上机、分析 | 按小时或按样本 |
| 场地与水电 | 洁净区、空调、纯水、电 | 按面积/时间分摊 |
| 失败重做 | 重复建库、重复上机 | 按失败率折算 |

## 2. 单样本成本公式

```text
C_sample = (C_reagent + C_consumable + C_labor + C_depreciation + C_facility) / (1 - p_fail)
```

- `p_fail`：该环节失败率（建库或上机）。
- 测序成本按 run 分摊：

```text
C_seq_sample = C_run / (N_samples × fill_rate)
```

- `fill_rate`：run 的装载利用率（pooling 不满时成本上升）。

## 3. 2026 年参考区间（示例）

| 项目 | 参考 | 来源 |
|------|------|------|
| 30× WGS（核心设施，含建库+测序+基础 QC） | 约 \$374/样本 | Lab Manager 2026 |
| DNA WGS 建库（KAPA 类） | \$30–155/样本 | LabX 2026 |
| Illumina mRNA-seq 建库 | \$137/样本 | Iowa 2026 |
| Illumina total RNA-seq 建库 | \$182/样本 | Iowa 2026 |

> 这些是“机构价/核心设施价”，不含你自己的人工与设备折旧；自建实验室通常更高，外包通常更低但排队。

## 4. 三个示例

### 4.1 30× WGS（外包核心设施）

```text
建库 + 测序 + 基础 QC ≈ 374 美元/样本
```

### 4.2 自建 RNA-seq（10 个样本）

| 项目 | 单价 | 数量 | 小计 |
|------|------|------|------|
| RNA 提取 | \$10 | 10 | \$100 |
| 建库 | \$150 | 10 | \$1,500 |
| QC（Qubit+TapeStation+qPCR） | \$25 | 10 | \$250 |
| 测序（run 分摊） | \$1,200 | 1 run | \$1,200 |
| 人工（按 \$30/h × 3 h/样本） | \$90 | 10 | \$900 |
| 失败重做（10%） | — | — | 约 \$395 |
| **合计** | | | **约 \$4,345（≈ \$435/样本）** |

### 4.3 16S（低深度、多样本）

建库便宜、测序按 run 分摊，单样本可压到 \$30–80；主要成本在提取与人工。

## 5. 规模效应

- **pooling 越满，单样本测序成本越低**；fill_rate 从 50% 提到 90%，测序分摊可降约 44%。
- 批次越大，试剂与耗材的“开机浪费”摊得越薄。
- 但批次过大增加失败波及面，需在成本与风险间平衡。

## 6. 敏感性分析

| 变量 | 变化 | 对单样本成本的影响 |
|------|------|--------------------|
| 建库失败率 | 5% → 20% | 成本上升约 19% |
| fill_rate | 90% → 60% | 测序分摊上升 50% |
| 建库试剂 | ±20% | 按建库占比线性变化 |
| 人工小时 | +50% | 按人工占比变化 |

## 7. 工具

```bash
python tools/cost_model.py --prices data/prices.csv --samples 10 --run-cost 1200 --fill 0.9 --fail 0.1
```

`prices.csv` 中每一行是一个成本项（名称、单价、按样本/按 run、数量），脚本输出分项与单样本合计。
