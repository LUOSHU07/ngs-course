# NGS 工作台（交互练习台 v2）

双击 `index.html` 打开，离线、无需服务器。

> **定位：学习的辅助工具，不是学习本身。** 课程文档（`../` 各章）是主体；本工作台提供练习支架——清单防漏、计算器防错、自测防"以为会了"、厂家协议防记错参数。新增功能的验收标准：它让课程里的哪一部分变得更容易学会？

## 九个视图（学习旅程）

导航按学习阶段分四组；概览内提供「学习路径」快速入口卡片。

| 视图 | 功能 |
|------|------|
| 概览 | 学习路径快速入口（与 M0–M10 进度联动）+ 进度环、M0–M10 勾选、已登记样本数、设备逾期数、自测最高分、上次单样本成本、下一步建议 |
| 我的实验台 | 勾选在用的试剂盒/设备 → 即时生成专属操作手册（步骤表+注意点+来源）；配置导出/导入 |
| 技巧库 | 39 条按模块（M0–M10）整理的技巧，支持关键词搜索 |
| 湿实验旅程 | 六步（样本登记→提取→建库→捕获→QC→上机，含清单/分步详解/计算器）+ 实验会话（5 模板、计时备注、历史 20 条） |
| 干实验 | 按 DNA/RNA 生成 fastp→比对→featureCounts 脚本（复制/下载）、QC 指标解读、常用命令、方法选型 |
| 设备与安全 | 20 台设备（卡片内嵌操作说明为主，维护记录为补充）+ 每日点检 + 故障速查 |
| 厂家方案 | 36 项已核对原厂协议（按步骤筛选+搜索）+ 61 项市场全景目录 |
| 核算 | nM 换算、等摩尔 pooling（可导出 CSV）、稀释（**0 偏差硬约束**：落在移液器刻度且浓度精确，取整偏好下保留精确解）、PhiX、单样本成本与敏感性表 |
| 自测与证明 | 35 题题库随机抽 10 题 + 错题本 + 学习证明打印 + 全部数据导出/清空 |

## 数据与隐私

- 全部数据存本机 `localStorage`（键 `ngs-workbench-v2`），不上传。
- 建议每周在「自测与证明」导出一次 JSON 备份。

## 测试

```bash
node test_calc.js        # 计算函数单测（与 Python 工具一致）
python check_ids.py      # app.js 引用的 DOM id 是否都存在
```

## 限制

- 纯前端，无后端；部分浏览器在 `file://` 下限制 localStorage。
- 已用无头浏览器截图验证「概览」视图（分组导航/学习路径卡/仪表盘布局）；其余视图建议在真实浏览器复核。
- 题库 35 题 + 错题本；新手引导（首次访问 5 步）；术语悬浮释义 24 条；学习证明打印；实验台配置导出/导入；样本→pooling/成本数据联动。
- 质量门禁：`python ../tools/qa_all.py`（9 关：语法×3、91 断言、运行时冒烟 47 检查、id 覆盖、厂家同步、断链审计、快照归档）。
