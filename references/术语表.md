# 术语表

| 术语 | 英文 | 含义 |
|------|------|------|
| NGS | Next-Generation Sequencing | 高通量测序，一次并行读取大量 DNA 片段 |
| WGS | Whole Genome Sequencing | 全基因组测序 |
| WES | Whole Exome Sequencing | 全外显子组测序 |
| RNA-seq | RNA Sequencing | 转录组测序 |
| 16S | 16S rRNA sequencing | 细菌 16S 扩增子测序，用于群落组成 |
| 文库 | Library | 带接头的、可上机的 DNA 分子集合 |
| 接头 | Adapter | 连接在片段两端的已知序列，用于扩增与测序 |
| Index | Index / Barcode | 文库标签，用于多样本混合后区分 |
| PhiX | PhiX Control | 测序质控用的已知序列对照文库 |
| 读长 | Read length | 单条序列长度，如 2×150 bp |
| 覆盖度 | Coverage / Depth | 某位点被读到的次数 |
| Q30 | Quality 30 | 质量值 ≥30 的碱基比例，错误率约 0.1% |
| PF | Passing Filter | 通过过滤的有效簇比例 |
| 簇密度 | Cluster density | 流动池上单位面积的有效簇数 |
| RIN | RNA Integrity Number | RNA 完整性评分，1–10 |
| DV200 | DV200 | RNA 片段中 ≥200 nt 的比例 |
| cfDNA | Cell-free DNA | 游离 DNA，常用于液体活检 |
| UMI | Unique Molecular Identifier | 分子标签，用于去重与定量 |
| 磁珠纯化 | Bead cleanup | 用磁珠选择性结合 DNA 去除杂质 |
| 末端修复 | End repair | 补平 DNA 末端 |
| 加 A | A-tailing | 3' 端加腺嘌呤 |
| 接头二聚体 | Adapter dimer | 接头自连形成的短片段，影响上机 |
| 定量 | Quantification | 测浓度或分子数 |
| 标准化 | Normalization | 消除样本间测序深度差异 |
| 差异表达 | Differential expression | 比较两组间基因表达差异 |
| 比对 | Alignment | 把 reads 定位到参考基因组 |
| BAM | Binary Alignment Map | 比对结果的二进制格式 |
| VCF | Variant Call Format | 变异结果格式 |
| 组装 | Assembly | 从 reads 重建基因组/转录组 |
| 注释 | Annotation | 给序列功能信息 |
| 批次效应 | Batch effect | 因批次不同引入的系统偏差 |
| 重复率 | Duplication rate | 相同 reads 的比例，过高提示扩增过度 |
