# 测序设备（1 类：MiSeq / DNBSEQ 系列）

> 测序仪是全实验室最贵也最"娇气"的设备：操作以厂家培训与官方指南为唯一准绳，本章给制度性要点与通用监控知识，**不替代厂家手册**；已核对的上机流程见[厂家方案库](../05-厂家方案/README.md)（MiSeq、MGI 环化）。

## 用途

MiSeq（Illumina，边合成边测序 SBS）与 DNBSEQ（MGI，DNB 滚环+联合探针锚定聚合）覆盖中小通量 run：panel、16S、小基因组、RNA-seq 小样。

## 测序原理（两平台的化学差异决定操作差异）

- **Illumina SBS**：文库单链固定在流动槽表面，经桥式 PCR 扩增成簇；每轮**同时加入四种**荧光标记的可逆终止核苷酸（凭荧光颜色区分碱基），成像后切除荧光基团与终止基团进入下一轮——逐碱基"拍照片"。因此簇密度（loading 浓度）直接决定数据质量，过密分不出簇、过稀产量低 [7]。
- **MGI DNBSEQ**：文库先环化成单链，滚环扩增成 DNA 纳米球（DNB），纳米球自组装到阵列化载片上，用联合探针锚定聚合测序（cPAS，源自 Complete Genomics 的 cPAL 连接测序 [8]）逐碱基读序。扩增在线性化的纳米球内进行、不在表面成簇，所以不存在 Illumina 式的簇密度问题，但**必须先完成环化与 DNB 制备**。
- 理解原理后再看操作：变性、loading、首轮信号监控都不是仪式，而是各自化学的前置条件。

## 标准操作（通用框架）

1. **run 前**：文库 QC 合格（浓度 qPCR/Qubit、片段 TapeStation）；按机型指南稀释、变性（Illumina：NaOH；MGI：环化后 DNB）；规划样本表与 index 冲突检查。
2. **装载**：耗材（flow cell / 载片、试剂槽）按编号核对；按指南加入文库与 PhiX/平衡文库；密封检查。
3. **运行**：启动后 30 min 内核对首轮信号（cluster 生成/DNB 装载率）——**前 30 min 是挽回失败 run 的最佳窗口**（尽早干预，具体可中止时机以厂家指南为准）。
4. **运行中**：每日查看 Q30、PF%、产量进度曲线；异常趋势（Q30 骤降、产量远低于规格）先查文库与试剂批次，再联系厂家。
5. **run 后**：按厂家规程清洗（wash）管路；导出数据并双备份；记录 run 参数与 QC 指标到 run 台账。

## 维护周期

- **每 run 后**：按厂家规程做仪器清洗（不给残留试剂结晶的机会）。
- **每月**：外观与废液管路检查；环境温湿度记录（测序仪对室温波动敏感，建议 19–25 ℃）。
- **每年**：厂家工程师预防性保养（PM）+ 性能验证 run；光学/流体系统按厂家计划校准。

## 故障处理

| 现象 | 最可能原因 | 处理 |
|------|-----------|------|
| 产量低 | 文库 loading 浓度偏低、变性问题、文库活性差 | 复核 qPCR 定量与变性流程；下一 run 调整并记录 |
| Q30 低 | 试剂批次/效期、文库质量、流体气泡 | 查试剂效期与存储；做清洗后复测 |
| PF% 低 | 簇过密或成簇失败 | 核对 loading 浓度计算（nM 换算最常见错误） |
| index 串扰高 | 游离接头残留、index hopping | 文库再纯化；换 UDI；NovaSeq 系更敏感 |
| 流体报错 | 管路堵塞/试剂结晶 | 执行厂家清洗程序；反复报错联系工程师 |

## 安全

- 试剂槽含甲酰胺等成分，按化学废液收集；
- 激光/光学部件勿直视拆解；
- 仪器移动必须由厂家执行（光路精密），实验室内部挪位也需报备。
