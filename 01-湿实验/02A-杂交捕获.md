# 操作卡 02A：杂交捕获（WES / panel）

> 对应模块 M2 的延伸；上游：文库构建与 QC；下游：捕获后 QC 与上机。
> 所有用量与温度**以探针/试剂盒说明书为准**；本卡给流程、判断点与记录要求。

## 目的

把全基因组文库中的**目标区域**富集出来，用更少的测序量获得更高的目标区深度。

## 前置条件

- [ ] 文库已完成 index 连接与纯化，Qubit、TapeStation、qPCR 合格。
- [ ] 每个文库总量 ≥500 ng（按捕获规模调整）。
- [ ] index 组合无冲突，避免捕获后无法区分。
- [ ] 探针在有效期内，Cot-1 已回温混匀（blockers 无需回温）。

## 材料与设备

探针（panel / exome）、Cot-1 DNA、universal blockers、index blockers、杂交缓冲液、链霉亲和素磁珠、洗涤缓冲液、磁力架、PCR 仪、qPCR 仪。

## 流程

### 1. 文库准备与混样

1. 按等摩尔比例混合 8–12 个文库，总投入 500 ng–1 µg。
2. 真空浓缩或纯化到适合杂交的体积。
3. 记录每个文库的实际投入量与 index。

### 2. 杂交

1. 加入探针、Cot-1、blockers 与杂交缓冲液，总体积按试剂盒（常见 20–30 µL）。
2. 95 ℃ 变性 10 min。
3. 迅速转入杂交温度、按探针说明书时间杂交（不要中断温度）：Twist 70 ℃ 16 h；IDT 65 ℃ 4 h（GC 富集/小 panel 可延 16 h）；Agilent SureSelect 65 ℃（时长见手册）。

### 3. 捕获

1. 链霉亲和素磁珠平衡至室温，洗涤后使用。
2. 将杂交产物与磁珠在 65 ℃ 结合 45 min，期间轻柔混匀。
3. 65 ℃ 严格洗涤，去除未杂交文库；洗涤次数与温度按试剂盒。

### 4. 捕获后 PCR

1. 用 index 引物扩增 10–14 循环。
2. 磁珠纯化，去除引物与 dimer。
3. Qubit、TapeStation、qPCR 检测。

### 5. QC 与上机

- 捕获效率：捕获后目标区域 reads 占比。
- 均一性：目标区域覆盖是否均匀，有无明显缺口。
- 污染：阴性对照与 index 交叉污染。

## 每步原理与技巧

> 来源锚点：杂交与洗涤机理见已核对协议 [Twist](../05-厂家方案/Twist-Target-Enrichment.md)、[IDT xGen](../05-厂家方案/杂交-IDT-xGen.md)、[Agilent SureSelect](../05-厂家方案/Agilent-SureSelect-XT-HS2.md)。

### 1. 杂交（为什么要在 65–70 ℃ 高温下杂交）

- **为什么**：探针是**带生物素标记的短单链**，与基因组里目标区域的序列互补，在合适温度下会特异性地"退火"配对。两个配角很关键：**Cot-1 DNA** 抢先占住基因组里的重复序列，防止探针被重复区"骗走"、结合到目标区以外；**blockers** 封闭文库接头序列，防止不同文库通过接头互相杂交——那是 index 串扰的温床。温度与盐度共同决定"要多少互补才配得上"，是特异性的总开关。
- **技巧**：变性后**不要中断温度**地转入杂交温度；杂交温度因平台而异（Twist 70 ℃、IDT 65 ℃、Agilent SureSelect 65 ℃），照自己的探针说明书，别照搬别的品牌。

### 2. 捕获（链霉亲和素下拉）

- **为什么**：探针上挂的生物素和磁珠上的链霉亲和素会强力结合——这是已知最强的非共价相互作用之一。于是"探针 + 目标片段"的杂交复合体被磁珠整个"捞"出来，没杂交上的杂散文库留在溶液里被倒掉。
- **技巧**：磁珠先平衡至室温、洗涤后再用；结合期间轻柔混匀，让磁珠和复合体充分接触。

### 3. 严格洗涤（把"错配"洗出去）

- **为什么**：磁珠上除了"完美互补"的目标，还挂着一些**部分错配**的杂散文库。提高温度、降低盐浓度会优先打断这些不稳定的错配杂交，只留完美互补——这正是富集的关键一步，也是"背景高"问题的分界线（见[案例库](../05-实践/故障案例库.md)）。
- **技巧**：洗涤温度与次数照说明书（Twist 48 ℃ 严格洗涤），别图快省洗——背景高的代价远大于多洗两遍。

### 4. 捕获后 PCR（把捞上来的放大）

- **为什么**：被捕获的目标分子量太少、上不了机，用 index 引物把**已带 index 的捕获产物**指数放大到上机量级。
- **技巧**：循环数照说明书（常见 10–14），过多会引入偏好与重复；纯化后照旧看 Qubit + TapeStation + qPCR 三件套。

## 关键参数

| 参数 | 常见范围 | 说明 |
|------|----------|------|
| 文库总投入 | 500 ng–1 µg | 按捕获规模与探针量调整 |
| 探针量 | 按试剂盒 | 过量增加背景，不足降低捕获效率 |
| Cot-1 | 按试剂盒（IDT 页 5 µL；其余待核对） | 封闭重复序列 |
| Blockers | 按试剂盒 | universal + index blockers |
| 杂交体积 | 20–30 µL | 体积过大降低杂交效率 |
| 杂交温度/时间 | 按探针：Twist 70 ℃/16 h；IDT 65 ℃/4 h（可延 16 h）；Agilent 65 ℃ | 温度波动影响特异性 |
| 捕获后 PCR | 10–14 循环 | 过多引入偏好与重复 |

## 判断标准

| 指标 | 合格表现 | 异常提示 |
|------|----------|----------|
| 捕获效率 | 目标区 reads 占比高 | 偏低 → 探针、杂交或洗涤问题 |
| 覆盖均一性 | 无明显缺口 | 缺口 → 探针覆盖或 GC 偏好 |
| 捕获后产量 | 满足上机 | 过低 → 循环不足或捕获失败 |
| dimer | 无明显小峰 | 明显 → 纯化不彻底 |

## 常见问题

| 现象 | 原因 | 处理 |
|------|------|------|
| 捕获效率低 | 探针过量/失效、杂交时间不足 | 换探针批次、延长杂交 |
| 背景高 | 洗涤不严、blockers 不足 | 提高洗涤温度/次数、补 blockers |
| 覆盖不均 | GC 偏好、探针设计 | 换 panel、增加测序深度 |
| 捕获后 dimer | 纯化不彻底 | 再做一次磁珠纯化 |
| index 交叉 | 混样或 index 冲突 | 核对 index 表，重做混样 |

## 记录

文库编号、投入量、index、探针批次、Cot-1/blockers 用量、杂交时间与温度、捕获后 PCR 循环、Qubit、TapeStation、qPCR、捕获效率。
