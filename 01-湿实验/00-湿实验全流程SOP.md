# 湿实验全流程 SOP：从样本到上机

> 适用：DNA-seq（WGS / WES / 16S）与 RNA-seq 的常规建库与上机。
> 原则：所有试剂与参数**以所用试剂盒说明书为准**；本 SOP 给流程、判断点和记录要求，不替代说明书。
> 逐项操作见：[01 样本与提取](01-样本接收与核酸提取.md)、[02 文库构建](02-文库构建.md)、[03 文库 QC](03-文库QC与定量.md)、[04 上机](04-上机与运行监控.md)。
> 各品牌逐步体积：[厂家方案库](../05-厂家方案/README.md)（36 项已核对协议）。

## 0. 安全与分区

- 人类样本按 BSL-2 操作；戴手套、口罩、护目镜，必要时在生物安全柜内处理。
- 单向流：**试剂配制区 → 样本处理区 → 扩增区 → 测序区**，人员和物品不逆行。
- 扩增区单独一套移液器与耗材；建库区避免开盖剧烈振荡，防止气溶胶。
- 废弃物、尖锐物、染料按实验室规定处理。

## 1. 样本接收与登记

1. 核对样本类型、数量、体积、保存条件、运输温度。
2. 编号规则：`项目号-样本类型-序号`（如 `P2026-001-B01`），全流程唯一。
3. 登记：接收时间、状态（溶血/凝固/降解）、保存位置（-80 ℃ 冻存盒坐标）。
4. 异常样本（量不足、严重降解、反复冻融）单独标记，建库前评估是否降级使用。

## 2. 核酸提取

### 2.1 gDNA

- 血液：按柱式或磁珠法血液 gDNA 试剂盒；注意裂解充分、洗脱体积。
- 组织：先匀浆，控制裂解时间，避免过度剪切。
- FFPE：需去交联，片段化程度高，建库输入量与片段选择要相应调整。

### 2.2 总 RNA

- 样本离体后尽快进入裂解液或液氮/-80 ℃，减少降解。
- 柱式或磁珠法；DNase 处理去除基因组 DNA。
- RNA 专用耗材与试剂，避免 RNase 污染。

### 2.3 质检

| 指标 | 方法 | 参考判断 |
|------|------|----------|
| 浓度 | Qubit（dsDNA / RNA） | 满足建库最低输入量 |
| 纯度 | NanoDrop A260/280、A260/230 | DNA ~1.8；RNA ~2.0；230 偏低提示盐/溶剂残留 |
| 完整性 | 琼脂糖凝胶 / Bioanalyzer / TapeStation | gDNA 主带完整；RNA 看 RIN / DV200 |
| 片段 | TapeStation | 记录主峰与弥散范围 |

## 3. 文库构建

### 3.1 DNA-seq（常规流程）

1. **片段化**：超声或酶法，目标片段按读长与试剂盒选择（常见 300–500 bp）。
2. **末端修复**：补平、磷酸化。
3. **加 A**：3' 端加腺嘌呤，便于接头连接。
4. **接头连接**：连接带 index 的 adapter；注意 index 组合避免冲突。
5. **纯化**：磁珠或柱式，去除未连接接头与二聚体。
6. **PCR 扩增**：循环数按输入量优化，避免过度扩增导致重复率升高。
7. **二次纯化**：去除引物二聚体，必要时做片段选择。

### 3.2 RNA-seq

1. **rRNA 去除或 mRNA 富集**（按试剂盒）。
2. **片段化**：控制片段大小。
3. **反转录**：一链合成。
4. **二链合成**。
5. **末端修复、加 A、接头连接、纯化**。
6. **PCR 扩增**：注意 index 与循环数。

### 3.3 关键控制点

- 输入量：DNA 常见 100–1000 ng；总 RNA 常见 100–1000 ng；cfDNA 可低至 1–10 ng（均以试剂盒为准）。
- PCR 循环数：输入越少循环越多，但循环过多会增加重复与偏好。
- 阴性对照：每批至少一个无模板对照（NTC），用于判断污染。
- UDG 处理：含尿嘧啶的体系按试剂盒要求处理，降低残留污染。

### 3.4 杂交捕获（WES / panel）

1. 文库 QC 合格，每个文库总量 ≥500 ng。
2. 8–12 个文库等摩尔混样，加入探针、Cot-1、blockers 与杂交缓冲液。
3. 95 ℃ 变性 10 min，转入杂交温度按探针说明书杂交（Twist 70 ℃ 16 h；IDT 65 ℃ 4 h，可延 16 h；Agilent SureSelect 65 ℃）。
4. 链霉亲和素磁珠捕获，65 ℃ 严格洗涤。
5. 捕获后 PCR 10–14 循环，纯化并做 Qubit / TapeStation / qPCR。
6. 详细步骤、参数与排查见 [杂交捕获操作卡](02A-杂交捕获.md)。

## 4. 文库 QC 与定量

| 项目 | 方法 | 看什么 |
|------|------|--------|
| 总量 | Qubit dsDNA | 是否有足够总量 |
| 片段分布 | Bioanalyzer / TapeStation | 主峰位置、adapter dimer、引物二聚体 |
| 有效浓度 | qPCR | 可扩增文库分子数，上机定量首选 |
| 纯度 | A260/280 | 蛋白/试剂残留 |

判断：主峰在预期范围、无明显 adapter dimer、qPCR 与 Qubit 结果比例合理（差异过大提示文库结构异常）。

## 5. Pooling 与上机

### 5.1 等摩尔 pooling

按文库的**摩尔浓度（nM）**计算，不用质量浓度直接等体积混。

```text
所需体积 V_i = (目标总摩尔数 × 该文库占比) / 该文库浓度
```

实操：先统一稀释到同一浓度，再按体积比混合；或按 `C1V1 = C2V2` 逐个计算。

### 5.2 PhiX

- 常规平衡文库：1%–5%。
- 低多样性文库（如 16S、扩增子）：适当提高比例，具体按平台建议。
- PhiX 按同一 loading 体系加入，混匀后上机。

### 5.3 变性与稀释

- 按平台/试剂盒要求进行 NaOH 变性、中和、稀释。
- loading 浓度以平台说明书为准；不同平台、不同试剂版本差异很大，不要照搬旧参数。

## 6. 运行监控

| 指标 | 含义 | 异常时先查 |
|------|------|------------|
| 簇密度 / 纳米球密度 | 上机模板量 | loading 浓度、变性是否充分 |
| PF% | 有效簇比例 | 簇过密、试剂过期 |
| Q30 | 质量值 ≥30 的碱基比例 | 试剂、流动池、温控 |
| 产出 | 总碱基数 | 读长设置、pooling 比例 |

## 7. 常见问题排查

| 现象 | 可能原因 | 处理 |
|------|----------|------|
| 文库总量低 | 输入不足、纯化损失、连接效率低 | 提高输入、优化纯化、检查试剂 |
| adapter dimer 明显 | 接头过量、纯化不彻底 | 调整接头比例、增加纯化 |
| qPCR 远低于 Qubit | 文库不可扩增、结构异常 | 检查末端修复/连接、重做 |
| 重复率高 | PCR 循环过多、输入过低 | 降低循环数、提高输入 |
| 低多样性报警 | 文库序列多样性低 | 提高 PhiX 比例 |
| 比对率低 | 污染、接头残留、物种不匹配 | 查阴性对照、trim、核对参考基因组 |

## 8. 记录表（每步必填）

- 样本编号、提取日期、方法、试剂批号、Qubit 浓度、A260/280、RIN/DV200。
- 建库：输入量、片段化方式、PCR 循环数、index、纯化倍数、批次。
- QC：Qubit、TapeStation 主峰、qPCR 浓度、结论。
- 上机：pooling 表、PhiX 比例、loading 浓度、运行编号、Q30/PF/产出。
